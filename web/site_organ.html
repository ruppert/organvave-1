OrganVave-1 v/*VERSION*/

A tonewheel-organ firmware for the M-VAVE FM-1: nine drawbars, a tone generator ported from setBfree, the key click, crosstalk and the swell, all in integer arithmetic on the FM-1's chip.

Not tested on a real FM-1 yet. Install it only if you can recover the device. This version has no built-in way back to the official firmware: keep M-VAVE's official firmware file before you start.

Um firmware de órgão de rodas tonais para o M-VAVE FM-1: nove drawbars, um gerador de som portado do setBfree, o click das teclas, o crosstalk e o swell, tudo em aritmética inteira no chip do FM-1.

Ainda não testado num FM-1 real. Instale só se você souber recuperar o aparelho. Esta versão não tem um jeito próprio de voltar ao firmware oficial: guarde o arquivo de firmware oficial da M-VAVE antes de começar.

Install

Instalar

Connect the FM-1 to this computer with its USB cable, then press Install. Use Chrome or Edge, on this page's https address or on localhost (the browser needs a secure context for MIDI with SysEx). The device stays in update mode until the install is finished: do not unplug it.

Conecte o FM-1 a este computador com o cabo USB e clique em Instalar. Use o Chrome ou o Edge, neste endereço https ou em localhost (o navegador exige um contexto seguro para MIDI com SysEx). O aparelho fica em modo de atualização até a instalação terminar: não desconecte.
